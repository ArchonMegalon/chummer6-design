# ALICE Build Ghosts Spec

ALICE is the build-branching horizon:

- branch a runner
- compare deltas
- explain drift
- restore or merge

Current posture:

- shipped as a bounded desktop and account lane
- public-safe ALICE route is live as an explainer/onramp, not as rule authority
- desktop ALICE exposes `Build help`, `Rules coach`, and `Origin Dossier`
- blank-state `Build help` can draft a complete starting runner without requiring an open character
- `Rules coach` explains selectable options such as legality posture, ware posture, qualities, and sequencing
- `Origin Dossier` can generate optional story/media context for new or finished runners without mutating mechanics
- GM allowances and requirements can seed ALICE guidance, including extra ware, extra availability, money, gear, qualities, required magical activity, illegal-addiction requirements, or minimum mental-attribute constraints
- ALICE must not silently apply mechanics, invent legality, or treat narrative output as deterministic character truth

## Native completion is a separate acceptance claim

[Finish my character](FINISH_MY_CHARACTER_ASSISTANT.md) defines the planned
Android Creation extension: complete a partially allocated runner while keeping
player choices locked, preview a validated diff and explicitly enter Career.
The existing blank-state Build help posture above does not establish that this
native route is implemented. It must use the runner's
[selected rulebooks](CHARACTER_RULEBOOK_SELECTION.md), not a global source default.
